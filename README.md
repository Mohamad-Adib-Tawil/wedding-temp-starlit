# دعوة زفاف محمد أديب طويل ورزان بطايحي

موقع دعوة ثابت يعمل على GitHub Pages. غيّر الأسماء والتاريخ والقاعة والنصوص والروابط ومسارات الصور من `wedding-config.js`.

## المعاينة المحلية

شغّل خادم ملفات ثابتة من هذا المجلد، ثم افتح `index.html` في المتصفح عبر الخادم حتى تعمل الصور وملف الإعدادات ومشغل الصوت.

## تأكيد الحضور

يفتح النموذج WhatsApp برسالة جاهزة تحتوي الاسم وخيار الحضور وعدد المرافقين والتهنئة. لا يخزن الموقع الردود على خادم.
